# App Icons

## Required Icon Sizes

Create PNG icons in these sizes:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## How to Create Icons

### Option 1: Online Generator (Easiest)
1. Create a square image (512x512 or larger) with your logo/artwork
2. Go to https://www.pwabuilder.com/imageGenerator
3. Upload your image
4. Download all generated icons
5. Copy them to this folder

### Option 2: Use an Artwork Image
1. Pick a square crop of one of Mr. Raut's paintings
2. Use any image editor to resize to 512x512
3. Use the PWA Builder link above to generate all sizes

### Option 3: Canva
1. Go to https://www.canva.com
2. Create a 512x512 design
3. Add initials "CRR" or a simple art-related design
4. Export and use PWA Builder to generate sizes

## Tips
- Use a simple, recognizable design
- Ensure it looks good at small sizes (72x72)
- Use bold colors that stand out on home screens
- Avoid too much detail - it won't be visible at small sizes
